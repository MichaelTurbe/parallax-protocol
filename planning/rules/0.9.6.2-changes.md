# Rulebook 0.9.5 → 0.9.6.2: changes that affect the system

These changes come from diffing the text of the two rulebook PDFs on 2026-10-22. Changes that are only flavor text, layout, or page numbers are left out.

## Mechanical changes

| Area | 0.9.5 | 0.9.6.2 | Handled in |
|------|-------|---------|------------|
| Skill training | A *trained skill bonus* per skill, starting at 4/3/2/1 depending on category priority | *Skill ranks*: each rank adds +1 to the skill. "Trained" means rank ≥ 1 | 0.1.0 |
| Character creation | Choose trained skills per category | Spend a budget of ranks per category: **16 / 9 / 4 / 1** (first → fourth priority). Max ranks per skill at creation: **4 / 3 / 2 / 1** | 0.1.0 |
| Leveling up | Raise the trained skill bonus of 4/3/2/1 skills by 1 | Raise the rank of 4/3/2/1 skills by 1 (per category, by priority). Any skill can be chosen, including untrained ones | 0.1.0 |
| Initiative | 1d20 + Awareness total bonus | **2d10** + Awareness total bonus | 0.1.0 |
| Combat shields | Item bonus to Deflection and Evasion contests | **Kinetic DR** of 1 / 2 / 3 (light / medium / heavy). Now one of four defensive mechanisms | 0.1.0 |
| Critical hits | Damage fields first, then armor | Damage order is **shield → field generator → armor** | 0.1.0 (reminder text in the chat card is not done yet; see roadmap) |
| Advantage text in "Running the game" | Still described a second d20 | Now 3d10, keep the highest or lowest two (the code already did this) | No change needed |
| Low gravity | +5 ft speed per tenth of a G below native | +5 ft per **fifth** of a G | Not modeled |

## Item and trait text changes

| Item | Old | New |
|------|-----|-----|
| Chameleon Cloak | +3 to Stealth | **Advantage** on Stealth checks |
| Tactical Helmet | +1 to Long Arms attacks and Gunnery | +1 to Long Arms attacks; **advantage** on Gunnery when interfaced with a ship |
| Prehensile tail (trait) | +2 to climbing Acrobatics/Athletics | Advantage on climbing tests |
| Buoyant Frame (trait) | +4 to swimming Athletics; no penalties in zero G | Advantage to swim; full speed in zero G and ignore disadvantage on Acrobatics, Athletics and Evasion |
| Ammonia-Based Hemolymph (trait) | Immune to poisonous inhalants | **+4 to Gas saves**; immune to ammonia and methane inhalation |
| Low-Temp Enzymes (trait) | Immune to cold, vulnerable to fire | Renamed **Psychrophilic Enzymes**: *resistant* to cold, vulnerable to fire |
| Amphibious (trait) | — | New morphological adaptation |
| Large (trait) | — | Load rating 6 + STR (moved, unchanged) |

Species traits are not shipped as compendium items yet, so the trait changes only matter once someone builds them.

## Errata noticed in the PDF

- The printed character sheet (p. 139) still has a **"Trained Skill Bonus"** column. It should say "Skill Rank".
- Starships: "jump drive" is now "drive rating", and FTL is "prismatic space" / "diving". This is terminology only; the system does not model starships.
