# 0.1.0: Rulebook 0.9.6.2 update

**Branch:** `feature/0.1.0` (from `develop`)
**Started:** 2026-10-22
**Rulebook:** Parallax Protocol 0.9.6.2 (see [rules/0.9.6.2-changes.md](../rules/0.9.6.2-changes.md))

## Goal

Bring the system in line with rulebook 0.9.6.2, mainly the switch from trained skill bonuses to skill ranks. Also fix the long-standing calculation gaps found while reviewing the code.

## Changes

Each item is its own commit on the branch.

- [x] Planning folder (this file, roadmap, decision log, rules notes)
- [x] Priority rules and hit die table moved into `PARALLAX` config
- [x] Skill ranks replace trained skill bonus; trained checkbox becomes derived and disabled; world migration
- [x] Rank budget tracker per category, plus a warning when a skill goes over the creation max at level 1
- [x] Priority dropdowns swap instead of allowing duplicates
- [x] Initiative is 2d10 + Awareness (combat tracker and sheet button)
- [x] Combat shields as a new item type giving kinetic DR
- [x] Item text updates for Chameleon Cloak and Tactical Helmet
- [x] DEX penalty from armor and fields applied to DEX-based skills
- [x] BURDENED speed penalty calculated from bulk
- [x] Body DR display-only (from species traits)
- [x] Version bump to 0.1.0 and documentation
- [x] Portrait opens full size in Foundry's image popout; a Change Image button below it opens the file picker (character and stat block sheets)
- [x] Mouse wheel no longer changes number inputs in Parallax windows
- [x] Effective DEX floored at 0; stats can't be entered below 0
- [x] DEX stat tile turns orange and shows effective DEX when an armor/field penalty applies

## Summary

**Status:** code complete on `feature/0.1.0` (2026-10-22). Not yet tested in a live world or merged to `develop`.

The derived-data math (rank totals and budgets, priority swaps, shield DR, DEX penalty, BURDENED) and the migration's data transform were checked outside Foundry, using a script that stubs out Foundry's classes. Sheet rendering, the migration's database write, and the combat tracker integration still need the manual checklist below.

**Follow-ups this release creates** (also in the roadmap):
- Re-run the item macros and the compendium sync so the packs pick up shield items, field generator penalties, and the new cloak and helmet text
- Characters carrying the old gear-type shields need them replaced

## Testing checklist (manual, in Foundry)

There is no automated test suite. After the branch is done, check in a live world:

1. A character from 0.0.30 opens and shows the same totals, with ranks equal to the old trained skill bonuses, and the migration notice appears once.
2. Typing a rank updates total, target, the trained checkbox and the category tracker without the sheet jumping.
3. Changing priorities swaps slots and updates the hit die when the first slot changes.
4. Initiative from the combat tracker and from the sheet both roll 2d10 + Awareness.
5. A shield adds to kinetic DR, and its DR is subtracted in the attack → damage chat flow.
6. Armor with a DEX penalty lowers DEX skills, never below an effective DEX of 0, and the DEX tile on the dossier turns orange with "eff. N (−P)".
7. Going over the load rating lowers speed by 5 ft per point of bulk over.
8. Clicking a portrait opens it full size (a GM can use Show Players); the Change Image button below it opens the file picker and is hidden for users who can't edit the actor.
9. Scrolling the mouse wheel over a focused number input scrolls the sheet and leaves the value alone.
